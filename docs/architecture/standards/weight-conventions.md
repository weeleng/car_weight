# C-03 重量规范

## 适用范围

VWCP 设备重量、原始数据留存、业务计算、正式称重记录和 API 输出。

## 已确认约束

| 层次 | 类型与单位 |
| --- | --- |
| VWCP 重量字段 | 有符号 `INT32`，克 |
| 业务标准重量 | `BIGINT`，克 |
| 正式重量 | `DECIMAL(12,3)`，千克 |
| API 正式重量 | 精确十进制表示，千克 |

- 保留原始重量数据，分别表达原始重量、毛重、皮重、净重、审核重量和计费重量。
- Java 以 `BigDecimal.valueOf(weightGrams, 3)` 等精确方式将克换算为千克。
- 支持 660L 单桶及 240L 双桶计量。存在父子记录时防止重复计费。

## 禁止事项

不得以修正值覆盖原始重量，不得在正式重量的换算、持久化或 API 链路使用二进制浮点代替精确十进制，不得对同一计量同时按父记录和子记录计费。

## 验证要求

针对舍入、边界、负值和重复事件提供测试。覆盖 INT32 边界、克到千克的精确换算、正式重量的存取及 API 精度，并覆盖单桶、双桶及父子记录重复投递下的计费结果。

## 来源与待核验内容

来源为 ENG-001B-01 提供的 C-03。正式舍入模式、负值业务处置、API 的线格式及双桶父子计费归属细则待核验。
