# DEC-001 至 DEC-018 人工审批材料

基线 `c9bc342f1a1324be200566db38e3460eed42eade`。[原始登记](open-decision-register.md)保留编号、优先级及开放状态。候选与建议用于人工评审；针对每组先评原则，再单独批准实现参数。证据按[人工审批模板](architecture-approval-record-template.md)录入。

建议评审次序为设备协议及安全 → 数据、权限及可靠性 → 称重与清运 → 财务与统计 → 接口及平台。第二组的事务、授权原则可与首组并行核对，财务规则可提前征询。

## 设备协议及安全

<a name="dec-001"></a>

### DEC-001 协议详细设计

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　RS485、蓝牙及云端传输边界不同，单套未分层协议会把升级耦合到三端。AA55、CRC16、小端仅为候选。评审帧长、类型、版本协商、兼容、非法帧及黄金向量。
- **既有约束**　分离控制板至终端的 VWCP 与终端至服务器契约，转发保留原身份，保持毫秒、INT32 克及 L2 提交条件。
- **候选 A**　终端保留原始帧并加版本化云封装；技术上易保留原证据，安全面集中于受控二进制解析，业务可追溯且财务不受转码，成本中等。
- **候选 B**　终端按版本规范化数据并一并保留原帧；云端契约易演进，需验证两种表示一致且完整，业务排障较容易，双端适配和存储成本更高。
- **建议及可批准原则**　建议先确认双契约和保真转发，优先评估带原帧封装，便于重放与互操作。可批准黄金向量及兼容策略原则。
- **待详细设计参数**　帧长度、偏移、CRC 变体/覆盖、最大长度、认证字段及兼容窗口。
- **实测及验收条件**　真实 RS485、BLE 和云端互操作，非法帧、截断、分包、粘包及升级的黄金样本验收。
- **关联及阻断范围**　ADR-013。C-02、C-03、C-04。工作包 G、H、I。限制VWCP 实现定版。按现有约束详细设计，改变约束时走 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

<a name="dec-002"></a>

### DEC-002 设备认证、事件身份和历史接收

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　设备 UID 只用于标识，撤销、换板、重启及历史补传需要可信关联。HMAC、AES-CMAC 或其他经审查方案，注入、轮换、撤销、换板，Epoch、Seq 生命周期及允许接收历史事件的边界。
- **既有约束**　逐设备凭据；用户、终端、设备和服务身份独立；同身份异载荷不覆盖。
- **候选 A**　评估 HMAC 路线；通用软件支持广，完整性依赖独立密钥与生命周期，利于快速联调，硬件与维护成本需量测，减少错归和计费风险。
- **候选 B**　评估 AES-CMAC 路线；可能复用芯片加速，需核对硬件及密钥隔离，认证能力按实现实测，换板及历史业务规则仍需治理，硬件工程成本待估。
- **建议及可批准原则**　建议先确认逐设备凭据、稳定身份与受控历史接收，按硬件实测和运维能力选路线。撤销后历史接收先保持人工可追溯核验。
- **待详细设计参数**　算法与参数、轮换时窗、事件身份编码、Epoch 持久化、Seq 回绕、历史证明与授权方式。
- **实测及验收条件**　授权测试环境复测离线、轮换、撤销、重启、身份冲突、换板及硬件资源消耗。
- **关联及阻断范围**　ADR-013, ADR-031, ADR-033。C-04、C-05。工作包 G、H、I。限制设备鉴权及去重定版。改变已确认身份或可靠性边界时需要 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

<a name="dec-003"></a>

### DEC-003 L2 ACK 编码与安全

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　服务器生成、终端接收及控制板接收事关未确认记录能否释放。成功、冲突、拒绝、重试如何表达并绑定原始身份，以及两类终端如何保真转发。
- **既有约束**　成功 ACK 仅在 INGEST 原始事件和 Outbox 持久提交后；异载荷冲突不能普通成功；未确认记录继续保留。
- **候选 A**　评估服务器生成端到端受保护回执；控制板可独立核验，缩小终端信任，防误释放和财务缺口，固件与密钥运维成本较高。
- **候选 B**　评估逐段受保护回执加可信终端绑定；利于适配已有硬件，终端成为额外信任边界，需审计转发且核验不误释放，集成复杂度中等。
- **建议及可批准原则**　建议原则上要求回执可验证、可关联且控制板确认后才可按策略释放。优先验证端到端路径，硬件适配困难时另审分段路径。
- **待详细设计参数**　载荷、状态编码、完整性保护、终端授权模型、重复和超时响应。
- **实测及验收条件**　两终端各测掉电、丢 ACK、终端收到但控制板未收到、同载荷重传、异载荷与认证失败，证明原始记录安全。
- **关联及阻断范围**　ADR-012, ADR-013, ADR-027, ADR-033。C-04、C-05。工作包 G、H、I。限制设备记录释放逻辑。改变提交条件时需要 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

<a name="dec-004"></a>

### DEC-004 离线容量、回收和满载

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　储存满载或断电可能永久丢失未确认称重。16 MiB 候选，容量按可用字节除以每条记录含索引与元数据的实测字节估算，再扣除保留与磨损余量。
- **既有约束**　无可靠成功 ACK 的事件禁止静默删除或覆盖。控制板与终端存储独立计量。
- **候选 A**　评估环形分段日志，仅回收已确认段；顺序写利于寿命，碎片/掉电需索引恢复，满载需告警和显式停收，成本中等，对业务影响可见。
- **候选 B**　评估事务式本地日志及独立索引；可按确认状态细粒度回收，写放大和索引一致性成本更高，需保护历史及避免未确认数据被低优先级挤出。
- **建议及可批准原则**　建议先确认已确认回收与满载告警，优先测分段日志，以简单路径降低断电恢复复杂度。
- **待详细设计参数**　容量、单条大小、对齐、校验、闪存寿命、回收顺序、停收及升级迁移。
- **实测及验收条件**　测最大记录和离线峰值、断电/重启、存储满载、升级恢复，证明没有静默覆盖。
- **关联及阻断范围**　ADR-013, ADR-027, ADR-037。C-04。工作包 G、H、I。限制设备与终端存储设计。放宽未确认保护需要 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

<a name="dec-006"></a>

### DEC-006 逻辑库部署、迁移与可靠消息

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　业务按三逻辑库演进，物理隔离和恢复成本随部署形态变化。物理实例、迁移工具、键、Publisher Confirm 与 returned、重试、死信、受控重放及恢复。
- **既有约束**　本地事务保持 INGEST 原始+Outbox、BUSINESS Inbox+业务+必要 Outbox；消费提交后确认，TRACK 独立。无跨库外键/事务。
- **候选 A**　同一 MySQL 实例三个逻辑库；初期低成本，备份简洁但故障和资源共享，可靠性按实例限制，采用分账号和权限，适合基础业务。
- **候选 B**　独立实例或集群；故障及访问域可隔离，跨库恢复点和对账复杂，运维成本高，适合已批准高可用需求。
- **建议及可批准原则**　建议允许按形态选择物理配置，先固定稳定身份、唯一约束和本地提交，基础环境优先考虑同实例，HA 单独验证。
- **待详细设计参数**　迁移实现、唯一列、权限、队列、退避、死信、重放入口与备份拓扑。
- **实测及验收条件**　MySQL 8.4 空库/升级，真实 MQ 丢确认及路由，并发、回滚、死信及跨库恢复对账。
- **关联及阻断范围**　ADR-006, ADR-012, ADR-014, ADR-036, ADR-037。C-01、C-04、C-05。工作包 C、E、F、I、S。限制存储与消息实现定版。更改三库边界或本地事务条件需要 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

### DEC-007 RFID 窗口及历史有效关系

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　上一桶缓存和迟到事件可能错配当前 RFID 绑定。多读卡器映射、缓存清除是否可确认、重叠有效期及终端迟到核验。
- **既有约束**　动作触发、清旧缓存、新读窗口、历史有效期；未知、不可信时间及冲突转授权人工，无默认归属或自动计费。
- **候选 A**　设备侧确认清除后采集携带窗口关联的新鲜读卡；误读风险较低且便于跨端核对，需固件及读卡器支持，改动中等。
- **候选 B**　终端协同标记窗口并验证新鲜读取；可兼容更多设备，通信中断或设备无法证明新鲜时须人工核验，运营成本较高。
- **建议及可批准原则**　建议优先验证设备侧读卡清除证据，同时确认服务侧必须按历史有效期匹配，失败时暂缓归属和计费。
- **待详细设计参数**　动作、地址、读卡器到桶配置、窗口、有效期重叠限制及人工规则。
- **实测及验收条件**　实机覆盖清除、双桶、离线迟到、停用、未知、换板、多标签及操作审计。
- **关联及阻断范围**　ADR-004, ADR-016, ADR-017, ADR-018, ADR-021。C-02、C-03、C-05。工作包 D、G、J、K、O。限制自动归属。按现有规范详细设计，偏离时需 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

### DEC-008 项目授权、缓存及异步上下文

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　项目级政府监管、跨租户数据与后台处理共享同一平台。权限解析位置、缓存失效、MQ/Quartz/线程池可信上下文，覆盖地图、导出、附件与聚合。
- **既有约束**　服务端默认拒绝，显式带时效的监管授权；缓存与异步不能越权，跨模块公开契约。
- **候选 A**　集中式授权服务计算范围并生成受控上下文；策略一致、易审计，故障面集中，业务延迟和缓存失效成本中等。
- **候选 B**　领域内统一策略库加各业务执行校验；局部可用性较好，需验证跨领域一致和版本，跨项目报表/财务越权风险和测试成本较高。
- **建议及可批准原则**　建议集中定义授权策略，保留领域对对象的最终校验。可评审政府授权范围、默认拒绝与每次后台执行的上下文清理原则。
- **待详细设计参数**　作用域键、过期与撤权延迟、TenantIgnore 例外及后台传播方式。
- **实测及验收条件**　跨租户/项目及撤权负例，MQ 重投、Quartz、线程复用、导出、附件、聚合、地图下钻。
- **关联及阻断范围**　ADR-003, ADR-004, ADR-005, ADR-007, ADR-025, ADR-026, ADR-031, ADR-036。C-02、C-05、C-06。工作包 D、E、M、Q、R。限制监管与共享读模型发布。改变正式模块或授权约束时需要 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

### DEC-015 关键审计、保留与防篡改

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　关键操作必须保留可审计证据，普通日志、归档与隐私生命周期不同。失败拒绝策略、保留、删除、完整性证据、跨域归档。
- **既有约束**　在所属事务保存审计证据或可重建证据的 Outbox。限制读取和删除，180 天仅为候选。

- **建议及可批准原则**　建议先确认本地可靠证据和独立校验，再按数据分类决定是否需要不可变归档。
- **待详细设计参数**　必审列表、保留与法定删除例外、脱敏、密钥、审批及故障策略。
- **实测及验收条件**　验证事务故障、删除和篡改探测、授权及脱敏、归档重放、备份与恢复。
- **关联及阻断范围**　ADR-029, ADR-030, ADR-032, ADR-039。C-02、C-05、C-06。工作包 C、D、E、R、S。限制关键操作及合规验收。降低已确认可靠性要求需要 ACR。
- **人工审批栏**　待人工确认。实际决定、范围、批准角色、时间、依据 SHA 和证据待填写。

### DEC-016 容量、拓扑及 S0/S1 口径

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　服务器生成和控制板收到 ACK 有不同观测点；故障域决定可恢复范围，含已提交未确认事件及 TRACK。RPO 分母、TRACK 分级、复制确认、故障切换、容量负载及可观测分段。
- **既有约束**　C-04 的本地提交是 ACK 必要条件，跨节点持久化与本地提交分开。S0 候选 RPO=0/RTO≤30 分钟限故障域，S1 候选 RPO≤5 分钟/RTO≤1 小时。
- **候选 A**　基础单机加备份；运行成本小，有节点丢失窗口，限制承诺，恢复及账务对账仍需证据。
- **候选 B**　多实例与持久化/复制保证的高可用方案；可验证指定故障域，须防双写和未确认数据遗漏，复杂度和成本高，保护正式称重及财务事实。
- **建议及可批准原则**　建议按形态审批保护集合与故障域，并分记提交、服务器生成、终端接收、控制板接收。先做拓扑对比及故障演练，后确认指标。
- **待详细设计参数**　复制保证、持久化参数、RPO 分母、容量剖面、报文大小、保留与 TRACK 角色。
- **实测及验收条件**　主库/磁盘/网络隔离、跨库恢复及第三方对账，分段采样和压测，按形态出具实测 RPO/RTO。
- **关联及阻断范围**　ADR-035, ADR-036, ADR-037, ADR-038, ADR-039。C-01、C-02、C-04、C-05。工作包 A、C、E、F、I、R、S。限制HA 定版及对外性能承诺。放宽 ACK 或持久化保证需要 ACR。

## 称重与清运业务

<a name="dec-005"></a>

### DEC-005 计量、舍入及双桶归属

**当前状态**　P0-DESIGN · 开放 · 未批准，待人工确认。

- **背景及未决问题**　660L 单桶与 240L 双桶需要保留原始、毛/皮/净、审核与计费重量。双桶独立计量能力、校准、滤波、窗口、负重与异常、舍入点。
- **既有约束**　INT32 克、BIGINT 克和 DECIMAL(12,3) 千克；保留原始，禁止父子双计及无证据均分。
- **候选 A**　逐桶确认独立传感与映射；精细归属及财务依据更强，需实车参考秤，硬件和校准成本较高。
- **候选 B**　组合重量作为作业事实，独立证据不足转待审；可靠保留原值且避免误计，复核运营成本上升，无法自动逐桶收费。
