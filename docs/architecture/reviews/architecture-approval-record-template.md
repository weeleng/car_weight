# 人工审批记录模板

每次记录一项实际决策及边界。多级授权分别签署并引用。固定被审 Git SHA、ADR 版本及证据位置。Git 来源、评审意见、合并与历史批准证据分别登记。历史正文或原批准记录按取得的原件登记。

## 审批类型

| 类型 | 允许记录的结论 | 需附输入 |
| --- | --- | --- |
| 既有统一约束确认 | 确认 C-01 至 C-06 的适用条款及出处 | 规范正文与[约束追溯](architecture-constraint-traceability.md) |
| 新架构原则批准 | 批准不变量、模块/数据所有权或方案范围 | 候选取舍及保留事项；改变正式约束进入适用 ACR 流程 |
| 专项详细设计批准 | 批准接口、参数或测试规格的指定版本 | 原则记录、设计、风险、验收与兼容计划 |
| 工程实施授权 | 授权工作包、分支、允许改动与验收 | 原则或详细设计记录、依赖就绪与任务边界 |
| 生产启用批准 | 授权指定功能、形态和版本，记录对应 BLOCK | 实际验收、剩余风险、恢复、回滚及签署 |

## 分类型附页

- **既有约束确认**　规范条款、版本、适用范围及保留验证待填写。
- **架构原则**　候选取舍、DEC、受影响 C 条款、获准原则及保留参数待填写。
- **专项详细设计**　原则记录、设计版本、参数范围、兼容性、安全和可靠性验证待填写。
- **工程实施**　包号、分支、起始 SHA、范围、硬依赖、交付、回滚及验收待填写。
- **生产启用**　BLOCK、环境和形态、被测 SHA、实际证据、批准范围、遗留阻断、复开条件待填写。

只有取得可核验历史证据时才登记原批准日期与原批准人。每次授权限于记录中的范围。
