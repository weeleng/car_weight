# ADR-019 清运线路管理

## 状态与版本

- 状态：`Proposed`
- 版本：草案 v0.1
- 起始基线：`ecd6ed655cec214a0ed945b6e5f2e21d3dc71ee6`
- 编号、标题和设计要点来自 ENG-001B-02C-02，候选映射与历史批准原文待核验。

## 决策来源

ENG-001B-02C-02 提供线路模型及 P0 候选范围。[ADR-017](ADR-017-asset-and-device-management.md)和 [ADR-018](ADR-018-merchant-and-waste-producer.md)提供车辆与服务点边界，[ADR-009](ADR-009-gis-architecture.md)负责 GIS 能力。

## 背景

可配置、复用和版本化的线路为作业计划、调度、清运执行、偏离监管及统计提供基础。线路模板、具体任务与真实轨迹分别建模。

## 决策

- 区分线路模板、线路版本、线路站点、计划路径、作业计划、执行任务与实际车辆轨迹。线路逻辑属性含标识、名称、租户、项目、垃圾类别、起终点、站点顺序、计划路径、预计距离和耗时、车辆类型、状态、生效时间与版本。
- 站点引用独立主数据，同一站点可被多条线路使用。候选包括商户服务点、公共收集点、中转站、处理设施、停车场及其他获准站点。访问顺序与空间位置分别维护。
- 支持人工配置固定线路、按模板生成计划、由 GIS 计算站点间路径。P0 建议优先固定线路、人工调整和基础规划。依车辆、站点、垃圾量和时间窗口优化，以及多车调度或动态重规划，留待专项。
- 规划考虑车辆类型和载重、垃圾类别与预计量、站点服务和车辆作业时间、设施接收条件、道路及车辆通行限制和起终点。用于垃圾车的路线须核验货车限行、尺寸及载重能力。
- 分别保留地图规划距离、计划作业距离、GNSS 实际轨迹计算距离和里程表数据，分别记录预计和实际作业耗时。评估漂移、缺失及异常点对实际距离的影响。
- 修改线路形成可追溯版本。已下发或已执行任务保留当时版本，执行中调整须经授权并留痕。拟基于计划线路与实际轨迹判断偏离，考虑临时封路、合法绕行、漂移、临时任务、线路版本、缺点及实际通行条件。
- 线路业务拟归 `sanitation-operation`，通过 `sanitation-gis` 的公开能力取得规划、坐标转换与空间计算。

## 适用范围

线路和站点、规划输入、版本、偏离监管及作业证据边界。

## 约束与禁止事项

禁止重复建立不可追溯的商户和设施档案，禁止将小客车路线直接当作垃圾清运车辆的合规路径。计划距离不覆盖实际记录，线路调整不静默改写历史任务。到站、进围栏与完成称重分别记录，经过站点不得直接生成正式称重或计费。偏离结果为候选监管事件，禁止自动定性违规。禁止跨模块引用内部 Mapper、DO 或 Biz。本草案不定义车辆调度算法。

## 备选方案及取舍

动态优化可提升利用率，但依赖约束及实时数据。固定模板和人工调整更易纳入审计，基础规划用于辅助并保留服务失败和人工确认路径。

## 与其他 ADR/ACR 的关系

空间与偏离见 ADR-009、[ADR-011](ADR-011-geofencing.md)和 [ADR-014](ADR-014-gnss-and-tracking.md)。车辆与主数据遵循 ADR-017、ADR-018。计划及调度、完成条件、偏离阈值及持续时间和告警规则分别关联候选 [ADR-020](README.md#adr-020)、[ADR-021](README.md#adr-021)、[ADR-022](README.md#adr-022)，正文仍待导入。适用 C-02、C-05、[C-06](../standards/module-boundaries.md)，出处见 [ACR-001 核对记录](../acr/ACR-001-reconciliation.md)。

## 验证要求

后续覆盖固定及多站点线路、站点复用、版本变更、规划失败、通行限制、计划与实际距离、临时调整、轨迹缺失、偏离、跨项目越权及到站与作业完成分离。

## 待确认事项

P0 范围、车辆限制支持，距离算法和统计口径，线路调整权限、偏离阈值及告警规则，以及调度与优化方案均待确认。
