# ADR-011 电子围栏与空间范围管理

## 状态与版本

- 状态：`Proposed`
- 版本：草案 v0.1
- 起始基线：`ecd6ed655cec214a0ed945b6e5f2e21d3dc71ee6`
- 编号、标题和设计要点来自 ENG-001B-02C-02，候选映射与历史批准原文待核验。

## 决策来源

ENG-001B-02C-02 提供围栏类型、候选几何及判定约束。[ADR-004](ADR-004-organization-and-project.md)、[ADR-005](ADR-005-user-and-permissions.md)及[轨迹草案](ADR-014-gnss-and-tracking.md)提供项目、授权与定位质量边界。

## 背景

围栏支持车辆作业监管、空间事件与后续告警。行政区、项目服务范围、作业责任区、电子围栏、线路走廊、服务点及设施位置可关联，各自保留业务语义。

## 决策

- 候选围栏包括项目服务区、清运作业区、收集点、中转站、处理设施、停车区、限入区和线路偏离检测区。
- 候选几何为圆、多边形、多多边形及线路缓冲区。须声明几何类型与坐标系，多边形校验闭合、有效性和自相交。围栏逻辑属性含标识、名称、类型、租户、项目、几何、坐标系、生效与失效时间、启用状态、适用车辆或作业范围和所需规则版本。
- 候选事件为进入、离开、停留、越界及路线偏离。记录定位、围栏版本和规则，考虑漂移、边界抖动、间隔、缺点、乱序和补传。连续判定、缓冲区、滞回与停留时间为降低误报的候选方式。
- 围栏修改后保留历史版本。迟到轨迹和离线补传按事件时间与当时规则核对，历史补算与告警修订留待事件管理专项。
- 确认租户与项目权限。政府监管依显式授权，地图可见范围与业务数据授权分别判断。

## 适用范围

业务空间对象、围栏配置与版本、空间事件和项目监管。

## 约束与禁止事项

禁止以单点无条件判定进入或离开、以当前围栏改写历史结果、以空间相交隐式授权跨租户访问。进收集点或处置设施仅为核验信息，禁止替代清运完成、正式称重、任务确认、处置凭证或计费依据。围栏异常不得阻断 INGEST 原始称重持久化。

## 备选方案及取舍

单点判断及时但误报易受定位质量影响。多点、缓冲或停留可抑制抖动，但引入延迟和参数校验。按专项选择组合。

## 与其他 ADR/ACR 的关系

遵循 [ADR-003](ADR-003-saas-tenancy.md)、ADR-004 和 ADR-005 的显式授权，使用 [ADR-009](ADR-009-gis-architecture.md)、[ADR-010](ADR-010-coordinate-system.md)与 ADR-014 的空间和轨迹能力，和 [ADR-019](ADR-019-collection-route-management.md)区分线路偏离与作业完成。适用 C-02、C-04、C-05、C-06，出处见 [ACR-001 核对记录](../acr/ACR-001-reconciliation.md)。

## 验证要求

后续覆盖进出、边界点、漂移、反复抖动、缺失、重叠、乱序、离线补传、版本变更、跨租户访问及围栏事件与作业完成的分离。

## 待确认事项

启用范围、带孔多边形及复杂边界、几何简化、判定参数、历史补算和告警修订待确认。
