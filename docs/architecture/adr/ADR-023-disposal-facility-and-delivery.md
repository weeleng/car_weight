# ADR-023 末端处置设施与垃圾交付

## 状态与版本

- 状态：`Proposed`
- 版本：草案 v0.1
- 起始基线：`f378d3f33d4b96f50eac15e3c361d012bd3b9891`
- 编号、标题及设计要点来自 ENG-001B-02C-03，候选映射与历史批准原文待核验。

## 决策来源

ENG-001B-02C-03 提供设施、运输批次和交付候选流程。[ADR-015](ADR-015-weighing-model.md)及 [ADR-024](ADR-024-contract-and-billing.md)约束车载称重及商户计费。只读核查 [FileController.java](../../../yudao-module-infra/src/main/java/cn/iocoder/yudao/module/infra/controller/admin/file/FileController.java)、[FileServiceImpl.java](../../../yudao-module-infra/src/main/java/cn/iocoder/yudao/module/infra/service/file/FileServiceImpl.java)、[FileDO.java](../../../yudao-module-infra/src/main/java/cn/iocoder/yudao/module/infra/dal/dataobject/file/FileDO.java)，文件服务可评估用于交付凭证管理，地磅、设施及交付业务未验证。

## 背景

车辆收运、运输及设施接收需要可追溯的凭证和重量核对。P0 拟先支持人工地磅录入及接收确认，自动地磅和第三方集成为后续候选。

## 决策

- 设施档案支持中转站、厨余处理及其他获准接收设施。属性含内部标识、名称、运营主体、租户或有效关联、地址和空间位置、垃圾类别、服务时间、接收能力、状态、项目及必要资质。设施与运营租户分开建模。
- 运输批次关联车辆、任务、收运时间范围、正式称重、垃圾类别、目标设施、交付记录和状态。可关联多个商户，任务支持多次卸载和多个批次。中转、合并和拆分待确认，同一份收运重量不得重复计入已确认批次。
- 候选流程为到厂、核验车辆和批次、进场计量、卸载、出场计量、计算接收净重、接收确认、形成交付凭证和重量核对。设施可按实际地磅模式调整。到厂围栏和卸载分别记录，接收方确认独立。
- 区分车载桶重、地磅车辆毛重、皮重、设施接收净重及审核交付重量，按 C-03 保持单位和精确数值。记录来源、时间、设施、车辆、操作员及凭证。凭证含交付单号、批次、类别、毛重、皮重、净重、接收时间、确认人、来源、附件及结果。重复提交按业务键控制，修正保留原记录及依据。
- 分别核算原始车载合计、正式有效收运合计、商户计费合计、设施接收净重及审核交付重。在相同批次、类别及统计范围中核对差异，考虑残留、其他载荷变化、液体流失、设备误差、漏记、混装与匹配错误。
- 后续可接入地磅、设施业务、政府监管和电子交付凭证系统。第三方接口须具备可信来源、幂等、错误处理与审计。P0 可手工完成。
- 设施主数据建议归 `sanitation-base`，批次及交付建议归 `sanitation-operation`，实际模块归属按 C-06 及现有映射确认。

## 适用范围

设施档案、运输批次、人工或自动计量、交付凭证及重量核对。

## 约束与禁止事项

禁止隐式共享项目数据、用车载 VWCP 事件身份作人工地磅业务键、伪装自动采集或按差异直接认定作弊和违规倾倒。车载精度目标不得用作差异阈值。设施接收重量不得覆盖、均分或按比例修正商户正式重量。依合同或明确规则决定商户计费是否等待交付，设施与运营企业结算须与责任主体账单分离。

## 备选方案及取舍

自动接口可减少手工录入，但依赖设施接口与可靠性验证。人工凭证先保留来源及审核记录，后续集成应沿用相同业务边界。

## 验证要求

后续覆盖人工录入、进出场计量、重复提交、多商户、多次卸载、重复批次关联、拒收、异常重量与差异、第三方重推、凭证修正、越权及商户计费重量保护。
