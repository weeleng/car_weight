# ADR-015 称重业务模型

## 状态与版本

- 状态：`Proposed`
- 版本：草案 v0.1
- 起始基线：`65af9b997071ff3a0e63c289b5ce33fd191d2696`
- 编号、标题及历史设计要点由 ENG-001B-02B-02 提供，候选映射及历史批准原文待核验。

## 决策来源

ENG-001B-02B-02 提供硬件形态、算法目标和逻辑记录模型。[C-03](../standards/weight-conventions.md)约束重量类型、精度和计费边界。

## 背景

支持 660L 单桶抱臂与 240L 双桶齿板。拟采用四路 HX711、500kg 与 800kg 两档传感器，接线包括激励正负、信号正负和屏蔽。通道分配、校准与机械安装待确认。

## 决策

- 用接近开关和重量采样识别举升、倾倒与下降。拟以举升阶段重量减去倾倒后下降阶段重量计算净重。拟议精度目标为相对误差绝对值小于 5%，尚无实测结论。
- 按 C-03 分别使用协议有符号 INT32 克、业务 BIGINT 克和正式 DECIMAL(12,3) 千克。区分原始传感器数据或采样重量、毛重、皮重、净重、审核确认重量及计费重量。
- 逻辑层次依次为原始称重事件、作业称重记录、必要的单桶明细、审核确认记录及计费依据记录。660L 可形成单桶记录，240L 须区分作业总量和各桶独立明细并明确计费粒度。此处仅描述逻辑模型。
- 一个原始事件应幂等生成业务记录。人工修正保留原始重量、修正值、原因、操作人和时间；入账后走可审计调整流程。
- 保留原始事件及异常原因。覆盖未知 RFID、识别失败、多标签冲突、负重、零重、传感器异常、举升或下降采样缺失、不完整倾倒、超量程、重复作业或 GNSS 缺失。是否生成待审记录或放行计费由后续异常分类和审批决定。

## 适用范围

两类称重作业、重量计算、计量明细、异常与审核、计费依据。

## 约束与禁止事项

禁止用浮点数表示正式计费重量，禁止修正覆盖原始数据或直接覆盖已入账数据。父级总量和子级明细不得同时计费。设备无法可靠区分单桶重量时，禁止均分总量作为正式计费依据。未知责任主体不得自动计费。

## 备选方案及取舍

作业总量适用于仅有可靠总量的情况，独立单桶计量可支持细粒度结算，但需要设备证据。分别记录总量与明细，由经批准的计费粒度择一使用。

## 与其他 ADR/ACR 的关系

接入事件与位置分别见 [ADR-013](ADR-013-vwcp-protocol.md)、[ADR-014](ADR-014-gnss-and-tracking.md)。作业 RFID 见 [ADR-016](ADR-016-rfid-identification.md)，计费依据见 [ADR-024](ADR-024-contract-and-billing.md)。遵循 [C-02](../standards/time-conventions.md)、C-03、[C-05](../standards/transaction-boundaries.md)及其 [ACR-001 核对记录](../acr/ACR-001-reconciliation.md)。

## 验证要求

后续覆盖 660L 单桶、240L 单桶或双桶作业、空桶、满桶、偏载、重复倾倒、重量边界与负值、未知 RFID、人工修正、精度和舍入及父子重复计费防护。

## 待确认事项

传感器映射、校准与安装、采样窗口、滤波、稳定判定、动态补偿、异常阈值、参考重量、载荷范围、重复性、精度验收及异常与计费审批规则待确认。
