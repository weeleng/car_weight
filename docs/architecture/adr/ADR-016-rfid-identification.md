# ADR-016 RFID 识别与绑定

## 状态与版本

- 状态：`Proposed`
- 版本：草案 v0.1
- 起始基线：`65af9b997071ff3a0e63c289b5ce33fd191d2696`
- 编号、标题及历史设计要点由 ENG-001B-02B-02 提供，候选映射及历史批准原文待核验。

## 决策来源

ENG-001B-02B-02 提供标签技术、读卡流程与历史绑定要点。[C-02](../standards/time-conventions.md)约束时间及质量信息，[ADR-015](ADR-015-weighing-model.md)约束称重事件关联。

## 背景

三个 ISO15693 读卡器拟通过 RS485 与 STM32 通信。读卡缓存可能仅保留最新一条，遗留卡号会误关联作业。

## 决策

1. 接近开关检测并确认倾倒或卸桶方向动作。
2. 清除相关读卡器旧卡号缓存，再启用本次作业的识别。
3. 获取当前识别窗口内的新卡号，关联有效结果并记录识别异常和冲突。

标签 UID 按 8 字节原始值保存，展示格式待确认。标签标识商户或其他垃圾产生责任主体，标签 UID 与商户 ID 分别记录。支持启用、停用、更换与重新绑定，绑定具有生效时间和历史记录。一个商户可绑定多个标签，同一标签在同一有效业务范围及时间内必须归属明确。

按称重事件的有效发生时间匹配当时的绑定。设备时间不可信时进入异常核验。标签未知、未绑定、已停用或冲突时，保留原始称重事件、识别结果和原因，允许人工核验及补充归属，记录操作审计。

## 适用范围

读卡缓存、作业识别、责任主体绑定历史与异常审核。

## 约束与禁止事项

禁止复用上一作业缓存、用当前绑定静默改写历史归属、默认绑定未知标签或自动形成商户计费依据。垃圾桶资产管理不列为 P0 必需范围。

## 备选方案及取舍

按当前绑定解析实现简单，但会使补传跨越绑定变更时归属错误。按事件发生时间解析需要有效期与质量核验，可保留历史归属。

## 与其他 ADR/ACR 的关系

协议及计费边界见 [ADR-013](ADR-013-vwcp-protocol.md)、[ADR-024](ADR-024-contract-and-billing.md)。与 ADR-015 按作业关联，遵循 C-02、[C-03](../standards/weight-conventions.md)、[C-05](../standards/transaction-boundaries.md)。约定来源见 [ACR-001 核对记录](../acr/ACR-001-reconciliation.md)。

## 验证要求

后续覆盖正常识别、残留卡号、清缓存失败、读取超时、多标签、停用、重绑、离线补传、历史归属、未知标签补录及跨租户或项目越权绑定。

## 待确认事项

读卡器地址、位置、范围、模式映射、UID 展示格式、清缓存命令及确认、识别窗口、重试次数、多标签策略与异常核验流程待确认。
